# SIGA logo source and reuse status

## Official source

The SIGA public website uses the following official logo asset in its site header:

- `https://siga.gov.gh/wp-content/uploads/2025/03/siga_logo-01-2048x565.png`

The source was checked and the original PNG was downloaded without modification on 22 October 2026. It is stored for the frontend at `frontend/public/branding/siga-logo.png`.

## Reuse authorization

The project owner reported receiving verbal authorization from their SIGA supervisor to use the official logo for this application. This is a reported verbal authorization; it is not represented as written approval or a documented agreement.

SIGA's [public notice on unauthorised use of its institutional identity](https://siga.gov.gh/press-releases/public-notice-siga-responds-to-unauthorised-use-of-its-institutional-identity-by-ceo-network-ghana/) states that use of the Authority's name or logo in connection with external material requires formal approval supported by a documented agreement. The logo should remain unmodified and this authorization should be revisited before any broader external distribution.
